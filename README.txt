AZAN AUDIO PLACEHOLDER
======================
Put a properly licensed, full-length Azan file in THIS folder and name it:

    azan_default.mp3        (.ogg / .m4a / .wav also work: azan_default.<ext>)

The app looks for any file starting with "azan_default" here. Until you add one,
Noor falls back to the phone's default alarm tone so scheduling can still be tested.
Users can also pick their own local audio file in Settings > Azan audio.

Do NOT ship audio you do not have the rights to redistribute.
